How to use this book: read a chapter, answer its Checks, do its practical task.

Learn Swift from your first program to building real apps and tools of your own, so you can write clear, safe, modern code you can actually use.

What this book is about

Swift is the language behind apps on Apple devices, and it is designed to be safe, fast and expressive — this book teaches it from the very beginning, one small idea at a time, with plain-words explanations and short Swift examples you can try as you go.

By the end you will have built real command-line tools and finished the SwiftDay task-and-notes manager capstone, giving you a finished project to show and a solid base for iOS development and Swift on the server.
