Section 2: map: Transforming Every Element

Map transforms every element of a collection using a closure you supply, and returns a new collection of the same length holding the transformed values. If you map an array of numbers with a closure that doubles each one, you get an array of doubled numbers, with the original array unchanged. Map is for one-to-one transformations, where each input produces exactly one output, and it is the most common collection method you will use. Because map returns a new collection, it fits the value-type style of Swift: the original data stays safe, and the transformed data is a separate, inspectable result.

Section 5: filter: Keeping What Matches

Filter keeps only the elements that satisfy a condition, called a predicate, and returns a new collection containing just those elements, in their original order for arrays. Filtering an array of numbers for even values, for example, removes the odd ones and keeps the evens, without changing the original array. Filter is for selection, not transformation: it never changes an element, it only decides whether each element stays or goes. That simplicity makes filter easy to reason about, and easy to combine with map, as you will see next.

Section 7: Combining filter and map

The order matters for meaning as well as efficiency, because mapping before filtering can change the values the predicate sees. Section 9: compactMap: Removing Nils

CompactMap transforms each element and discards any result that is nil, which makes it ideal for parsing, where some inputs convert successfully and others do not. Mapping an array of strings with Int.init, for example, produces nil for non-numeric strings, and compactMap removes those nils, leaving only the successfully parsed integers. Without compactMap, you would need a separate filter step to remove nils, followed by unwrapping, which is both longer and easier to get wrong. CompactMap combines transformation and cleanup in one step, and its name is a reminder that the result is compacted, with gaps removed.

Section 10: flatMap: Flattening Collections

FlatMap transforms each element into a collection and then flattens the results into a single collection, removing one level of nesting. If each student has a list of courses, flatMap over students produces one flat list of all courses, instead of a list of lists. This is useful whenever your data is naturally nested but the task needs a flat view, such as gathering all tags from a list of posts. FlatMap is sometimes confused with compactMap, because older Swift used flatMap for nil removal too, but in modern Swift the two jobs are separate: flatMap flattens collections, compactMap removes nils.

Section 12: reduce into Dictionaries and Groups

Reduce can build more than a number or a string: it can build a dictionary, a set, or any other value, by starting from an empty container and adding to it for each element. Counting how many times each word appears, for example, starts from an empty dictionary and increments the count for each word encountered.
