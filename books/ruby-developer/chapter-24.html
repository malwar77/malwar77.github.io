Check: Why does Review: files at a glance matter for programs you want to build later, in your own words?

Practical Task

Build a small Ruby program called file_notes.rb that writes five notes to a text file, appends one more note, reads the file back line by line, and prints each line with its line number. Handle a missing file with a friendly message, check whether the file exists before reading, and make a backup copy of the file before overwriting it. Test it by running it twice, deleting the file and running it again, and writing down what happened each time.

Chapter Questions

  1. Why is it safer to open a file with a block than to open it and close it by hand?
  2. What is the difference between writing to a file and appending to a file?
  3. What should a program do when the file it wants to read does not exist?
  4. Why should you read a large file line by line instead of loading it all at once?
  5. How would you design a notes program that never loses notes when it crashes while saving?
