How to use this book: read a chapter, answer its Checks, do its practical task.

Learn AI from your first intelligent program to building real local tools of your own, so you can understand how AI works, use it safely, and build things you can actually trust.

What this book is about

This book teaches AI in plain words, from data and patterns to language models, prompting, agents, evaluation, fairness, privacy and safety — with short Python standard-library examples you run on your own machine, no API keys or paid services needed.

By the end you will have built AIDay, a local personal assistant toolkit in Python using only the standard library — a note summariser, a local search tool over your own notes, and a task helper with plain-text storage — giving you a finished project to show and a solid, safety-first base for real AI work.
