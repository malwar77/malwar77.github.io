Section 1 — The capstone project: MyDay Dashboard

This section covers the capstone project: myday dashboard. MyDay Dashboard is a small personal dashboard for tasks and notes, built with only HTML, CSS and JavaScript, with no framework and no server. It has a tasks panel, a notes panel, and an overview panel that counts tasks and shows progress.

Good front-end work connects the capstone project: myday dashboard to the rest of the project, so a change here should not silently break a filter, a count, or a saved list elsewhere.

Here is a short example from the MyDay Dashboard:

<header>
  <h1>MyDay Dashboard</h1>
  <p>Tasks and notes, in one calm place.</p>
</header>
