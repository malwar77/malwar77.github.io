Section 1: What a Typography System Is

In plain words, what a typography system is describes how type is chosen and arranged for readers. A typography system is a small set of sizes, weights, and spacings used consistently. Without such a system, headings and paragraphs drift into many unrelated sizes. Start with body text, because most reading happens there, not in headings. Body text needs a comfortable size, a generous line height, and a sensible line length. Headings then step up from body text in clear, repeatable jumps. Line height matters as much as font size, especially in long paragraphs.
