How to use this book: read a chapter, answer its Checks, do its practical task.

Learn CSS from your first stylesheet to styling real websites of your own, so you can build layouts that look good, work on any screen, and are easy to maintain.

What this book is about

This book takes you from your first CSS rule to styling real websites you can actually use. You will learn selectors and the cascade, colours and typography, the box model, flexbox and grid, positioning, components, transitions and animations, variables, responsive design, accessibility, dark mode and print styles — then move into modern features like container queries, layers and nesting.

Along the way you will work with real examples you can open in a browser, understand how browsers lay out a page and how to debug styles that do not look right, and finish by planning, styling and polishing a complete site of your own. By the end, you will be able to write clear, maintainable CSS, build responsive layouts without a framework, and finish a project you can show to others.
