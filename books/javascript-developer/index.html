What this book is about

This book takes you from your first JavaScript program to building real web apps you can actually use. You will learn values and types, strings and numbers, decisions and loops, functions, arrays and objects, classes, the DOM and events, asynchronous code, fetching data from APIs, JSON, error handling, storage, canvas and animation, routing and state — then move into testing, accessibility, performance, security and tooling.

Along the way you will work with real examples you can run in a browser, understand how JavaScript programs are put together and how the web page, the network and your data fit together, and finish by planning, building and polishing a complete application of your own. By the end, you will be able to write clear JavaScript code, build interactive and data-driven web apps, and finish a project you can show to others.
