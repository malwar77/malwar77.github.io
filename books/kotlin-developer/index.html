How to use this book: read a chapter, answer its Checks, do its practical task.

Learn Kotlin from your first program to building real apps and tools of your own, so you can write clear, safe, modern code you can actually use.

What this book is about

This book takes you from your first Kotlin program through variables, decisions, loops, functions, collections, classes, null safety, generics, files, coroutines, testing and more, all in plain language with a short Kotlin example in every section. Each of the 50 chapters ends with a practical task and five questions, so you practise as you learn rather than just reading about the language.

You finish by planning, building and polishing KotlinDay, a command-line task-and-notes manager in Kotlin using only the standard library — Main.kt, Task and Note data classes, a plain text file for storage, and add, list, done and search commands — a complete tool you can show, extend and keep building on.
