How to use this book: read a chapter, answer its Checks, do its practical task.

Learn cyber security from your first defence to protecting real accounts, devices and networks of your own, so you can stay safe online and help others do the same.

What this book is about

This book teaches cyber security in plain words, from passwords and phishing to encryption, backups, incident response and authorised testing — always defence first, always on systems you own or have permission to test, with short Python examples for your own checks.

By the end you will have built CyberGuard, a defensive personal security audit toolkit in Python using only the standard library, giving you a finished project to show and habits you can use every day.
