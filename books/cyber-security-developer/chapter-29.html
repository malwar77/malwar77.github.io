Section 1: What Incident Response Means

Incident response is the planned way people and organisations react when something goes wrong with security, so that damage is limited and normal work can return safely. You do not need to be an expert to use this idea well. You need a simple habit, a short pause, and a trusted way to check before you act.

One key idea here is why a plan made before an incident works better than improvisation. Watch for the common mistake connected to this point, which is usually acting first and checking later. Reversing that order changes the outcome: check first, using a channel you trust, and only then decide. Checking first costs a few minutes; recovering later can cost weeks.
