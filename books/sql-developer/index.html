Learn SQL from your first query to working with real databases of your own, so you can ask good questions of data, design tables well, and build systems you can actually use.

What this book is about

This book takes you from your first SELECT statement to working with real databases you can actually use. You will learn filtering and sorting, aggregates and grouping, joins of every kind, subqueries, functions for text, numbers and dates, views and indexes, transactions and permissions, normalisation, window functions and common table expressions — then move into query performance and safe, parameterised code.

Along the way you will work with fictional data you can practise on safely, understand how a database is designed and how queries are planned and run, and finish by planning, building and polishing a complete database of your own. By the end, you will be able to write clear SQL, design well-structured tables, answer real questions from data, and finish a project you can show to others.
