Chapter 6: Making Decisions with if and else

Section 1: What an if Statement Does

What an if Statement Does is the focus of this section, and it belongs to the wider topic of if and else decisions in Go. Learning if and else is learning to describe a decision in code the way you would describe it in words, and then trusting the computer to follow that description exactly. You state the condition, you state what happens when it is true, and optionally you state what happens otherwise. Keeping that picture in mind makes it much easier to predict what a program will do before you run it.

Conditions are built from comparisons and logical operators. Comparison operators such as equal, not equal, less than and greater than compare two values of compatible types and produce a boolean result. Logical operators combine booleans: AND requires both sides to be true, OR requires at least one side to be true, and NOT flips a boolean value. Go evaluates AND and OR from left to right and stops early when the result is already decided, a behaviour called short-circuit evaluation. That early stop matters when the right-hand side would be expensive or unsafe to evaluate, such as checking a value only after confirming it exists.

Write down the value of each variable, evaluate the condition step by step, and mark which branch runs. Then run the program and compare the real output with your prediction. Boundary values are where decision bugs love to hide, so they deserve deliberate testing.

Another pitfall is writing a condition that is almost right but wrong at the boundary, for example using greater than when greater than or equal to was meant. Off-by-one boundary errors are quiet because the program still runs and looks correct for most inputs. Testing with the exact boundary value, one below it and one above it, catches them quickly. Also watch for conditions that can never be true or can never be false, often because two parts contradict each other. If a branch never runs in testing, ask whether the condition itself is wrong or whether your test data never reaches it.

import "fmt"

func main() {
	// What an if Statement Does
	age := 20
	if age >= 18 {
		fmt.Println("Old enough")
	} else if age >= 13 {
		fmt.Println("Teenager")
	} else {
		fmt.Println("Child")
	}
}
