How to use this book: read a chapter, answer its Checks, do its practical task.

Learn C# from your first program to building real console applications of your own, so you can write clear, well-structured .NET code and build software you can actually use.

What this book is about

This book takes you from your first C# program through variables, decisions, loops, methods, collections, classes and objects, LINQ, files, async code, testing and security, all in plain language with a short, runnable example in every section. Each of the 50 chapters ends with a practical task and five questions, so you practise as you learn rather than just reading about the language.

You finish by planning, building and polishing CsDay, a console task-and-notes manager with add, list, done and search commands, built with the .NET base class library only — a complete program you can show, extend and keep building on.
